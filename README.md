# React Native Maps

A React Native maps library with a native map surface that renders markers and routes from application state. It supports Google Maps on Android, MapKit on iOS, and optional Google Maps on iOS. Nitro Modules provides the native bindings.

- [API guide](docs/api.md) covers features, surfaces, styling, and gestures.
- [Architecture](docs/architecture.md) describes state ownership and native integration.
- [Validation guide](docs/validation.md) covers the Expo example, local checks, and platform coverage.

Start with the [example app](example/App.tsx) or the [documentation index](docs/README.md).
